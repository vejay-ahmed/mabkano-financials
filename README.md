## Getting started

These instructions will help you run the project locally.

1. Clone the repository

   git clone https://github.com/vejay-ahmed/mabkano-financials.git
   cd mabkano-financials

2. Open index.html in your browser

   - You can open the file directly in your browser (double-click `index.html`), or run a local static server:

     python3 -m http.server 8000
     # then open http://localhost:8000 in your browser

3. (Optional) Use a live-reload server for development

   - Recommended: use an editor extension or a tool like `live-server` or the built-in dev server in VS Code.
